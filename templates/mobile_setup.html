Mobile Setup

Reference for setting up Nodebook on a phone or tablet - installing the app, and sharing images straight into Reference from your device's share sheet. The values below are live: if the API key is ever rotated, this page updates on its own.

Install the app

iOS: open this site in Safari, tap the Share button, then Add to Home Screen. Safari has no one-tap install option - this is the only path on iOS.

Android (Chrome): open this site, and either wait for the install banner, or use the Install App button on the login page if Chrome offers it. If it's already installed, neither will appear.

Key values

Both setups below need these two things.

Share-target URL {{ share_target_url }}
Header X-API-Key: {{ api_key }}
Form field name images
{% if not api_key %}

No API_KEY is set in this server's .env - the sharing shortcuts won't authenticate until one is added and the container is restarted.

🎮 iOS - Apple Shortcuts

Uses the built-in Shortcuts app - no install needed.

  1. New shortcut → enable Show in Share Sheet, type Images.
  2. Add Convert Image → JPEG (handles HEIC photos from Photos).
  3. Add Get Contents of URL → POST to the share-target URL above.
  4. Under Headers, add the X-API-Key header above. Under Request Body, choose Form, add a File field named images, and set its value to the converted image (the Convert Image step's output) - not the raw Shortcut Input.
  5. Order matters: Convert Image must come before Get Contents of URL, or the file field will have nothing valid to reference.
Import the working shortcut

This imports a copy of the confirmed-working shortcut directly - only needs the URL/key above if you ever rebuild it from scratch instead.

🤖 Android - HTTP Shortcuts (Waboodoo)

Third-party app (Play Store / F-Droid) - Android has no built-in equivalent.

  1. New shortcut, method POST, URL from above.
  2. Add the X-API-Key header. Do not add a Content-Type header - form-data needs to set its own automatically.
  3. Request Body Type → Parameters (form-data) → add a field, type File, name images. File Data Source can be left as "Open file picker" - it's only used for manual runs, not real shares.
  4. Trigger & Execution Settings → enable Allow receiving files from share dialog.

Equivalent curl command

curl {{ share_target_url }} -X POST -H "X-API-Key: {{ api_key }}" -F images=@file

Backing up a shortcut

HTTP Shortcuts: main menu → Import/Export → Export → save the .zip somewhere durable (email to yourself, Drive) - not just on the phone.

Apple Shortcuts: long-press the shortcut → Share → Save to Files (pick iCloud Drive), and/or Copy iCloud Link for quick reimporting on another device.

Both backups contain your real API key. Keep them private - don't post either one anywhere public.
